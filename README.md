# Le Chemin vers Toria — Site surprise d'anniversaire

Site web personnel et interactif créé comme surprise d'anniversaire : un parcours illustré avec photos, vidéo et musique.

**Démo :** https://zacksslecapitaine1-pixel.github.io/Toria/

## Stack technique

HTML · CSS · JavaScript (sans framework)

## Architecture

```
Toria/
├── index.html      page et styles
├── app.js          logique et animations
├── assets/
│   ├── img/        photos
│   ├── audio/      musique (piano)
│   └── video/      vidéo
└── .nojekyll       publication GitHub Pages sans traitement Jekyll
```

## Déploiement

Site statique publié directement depuis la branche `main` via GitHub Pages.
